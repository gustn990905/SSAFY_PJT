# 🥗 YumYumCoach (냠냠코치)

## 💡 프로젝트를 통해 느낀 점

* 김서연

이번 프로젝트를 수행하면서 하나의 웹 서비스를 직접 구현해보는 과정이 매우 뜻깊게 다가왔습니다. 
단순히 개별 기능을 구현하는 데 그치지 않고, 회원 관리, 식단 기록, 커뮤니티와 같은 다양한 기능이 하나의 서비스 안에서 유기적으로 연결되는 과정을 경험하며 
웹 서비스 전반에 대한 이해를 넓힐 수 있었습니다. 
특히 프론트엔드는 사용자가 서비스를 처음 접하고 지속적으로 경험하는 영역이라는 점에서, 
단순한 화면 구성을 넘어 서비스의 편의성, 완성도, 그리고 전반적인 인상을 결정짓는 중요한 역할을 한다는 것을 깊이 느꼈습니다. 
이번 프로젝트를 통해 프론트엔드의 중요성을 더욱 실감할 수 있었으며, 
사용자 관점에서 더 직관적이고 완성도 높은 서비스를 구현할 수 있는 개발자로 성장하고 싶다는 목표를 갖게 되었습니다.

---

* 김현수

이번 프로젝트를 진행하면서 수업에서 배운 HTML, CSS, JavaScript를 실제 서비스 형태로 구현해볼 수 있었습니다.  
단순히 이론으로 이해하던 내용을 직접 활용해서 실제 기능처럼 구현해보니 배운 내용을 더욱 활용할 수 있었고, 이를 통해 실력이 한 단계 더 향상된 것 같다는 느낌을 받았습니다.

또한 식단 관리, 회원 관리 등 여러 기능을 구현하다 보니 점점 욕심이 생겨 단순히 요구된 필수 기능을 넘어서 더 다양한 기능을 추가해보고 싶다는 생각이 들었습니다. 그래서 팀원과 함께 추가 기능까지 도전해보며 프로젝트를 더욱 확장해볼 수 있었습니다.

다만 기능 구현에 많은 시간을 사용하다 보니 CSS 디자인을 충분히 다듬지 못한 점이 아쉬움으로 남습니다. 만약 시간이 더 있었다면 UI를 조금 더 정교하게 다듬어 사용자 경험을 더욱 개선해보고 싶다는 생각을 했습니다.

---

# 📊 데이터 기반 실시간 식단 분석 및 스마트 건강 관리 플랫폼

**냠냠코치(YumYumCoach)**는 사용자의 **식단 데이터를 기록하고 분석하여 개인 맞춤형 건강 정보를 제공하는 Front-end 기반 웹 서비스**입니다.

단순한 식단 기록을 넘어 **AI 기반 식단 분석, 건강 리포트, 커뮤니티 소통 기능**을 결합하여 사용자가 **건강한 식습관을 지속적으로 관리할 수 있도록 지원합니다.**

또한 **LocalStorage 기반 데이터 관리 구조를 활용하여 실제 서비스와 유사한 사용자 경험(UX)**을 구현하였습니다.

---

# 🚀 프로젝트 핵심 기능 (Core Features)

본 프로젝트는 단순 CRUD 구현을 넘어 **데이터 간의 유기적인 연결성과 실시간 사용자 인터랙션을 중심으로 설계되었습니다.**

---

# 👤 1. 회원 관리 시스템 (F206 ~ F211)

서비스 이용을 위한 **회원 관리 및 사용자 관계 기능**을 구현하였습니다.

LocalStorage를 활용하여 **사용자 정보를 저장하고 로그인 상태를 관리하는 구조**로 설계되었습니다.

---

## 📌 F206 회원 가입

사용자는 회원가입을 통해 서비스 이용을 위한 계정을 생성할 수 있습니다.

입력 정보

- 아이디
- 비밀번호
- 이름

회원 정보는 **고유 사용자 ID 기반으로 LocalStorage에 저장**됩니다.

---

## 📌 F207 회원 정보 조회

로그인한 사용자는 자신의 회원 정보를 조회할 수 있습니다.

제공 기능

- 회원 기본 정보 조회
- 로그인 사용자 정보 확인

이를 통해 사용자는 **자신의 계정 상태를 확인할 수 있습니다.**

---

## 📌 F208 회원 정보 수정

사용자는 자신의 회원 정보를 수정할 수 있습니다.

수정 가능 정보

- 비밀번호
- 이름 등

수정된 정보는 **LocalStorage에 즉시 반영되어 업데이트됩니다.**

---

## 📌 F209 회원 탈퇴

사용자는 회원 탈퇴 기능을 통해 서비스 이용을 종료할 수 있습니다.

제공 기능

- 회원 정보 삭제
- 계정 비활성화

이를 통해 **사용자의 데이터 관리 권한을 보장합니다.**

---

## 📌 F210 로그인 및 로그아웃

사용자는 아이디와 비밀번호를 통해 로그인할 수 있습니다.

기능

- 로그인 인증
- 로그아웃
- 로그인 상태 유지

로그인 여부에 따라 **접근 가능한 메뉴와 페이지가 달라지는 구조를 구현했습니다.**

---

## 📌 F211 팔로우 / 팔로잉 시스템 (추가 기능)

사용자는 다른 사용자를 팔로우하여 **소셜 네트워크 기능을 활용할 수 있습니다.**

제공 기능

- 사용자 팔로우
- 팔로우 취소
- 팔로잉 목록 조회
- 팔로워 목록 조회

이를 통해 **사용자 간의 연결 관계를 형성할 수 있는 구조를 구현했습니다.**

---

# 🥗 2. 지능형 식단 관리 및 실시간 영양 분석 시스템 (F201 ~ F205)

사용자가 입력한 식단 데이터를 기반으로 **실시간 영양 분석과 건강 리포트를 제공하는 핵심 기능**입니다.

---

## 📌 F201 식단 정보 등록

사용자는 **Form 기반 입력 시스템**을 통해 식단 데이터를 등록할 수 있습니다.

등록 항목

- 음식 이름
- 섭취 시간
- 섭취량
- 메모

입력된 데이터는 **고유 식단 ID 기반으로 LocalStorage에 저장됩니다.**

---

## 📌 F202 식단 정보 조회

사용자는 저장된 식단 정보를 **목록 형태로 확인**할 수 있습니다.

제공 기능

- 전체 식단 기록 조회
- 식단 ID 기반 상세 조회
- 날짜별 기록 확인

---

## 📌 F203 식단 정보 수정

기존 식단 데이터를 선택하여 **정보 수정이 가능**합니다.

수정 과정

1. 기존 데이터 자동 로딩
2. 입력 값 수정
3. 저장 후 즉시 반영

---

## 📌 F204 식단 정보 삭제

등록된 식단 데이터를 **식단 ID 기준으로 삭제**할 수 있습니다.

제공 기능

- 개별 식단 삭제
- 삭제 후 목록 자동 갱신

---

## 📌 F205 AI 기반 식단 분석 및 건강 점수 시스템

입력된 식단 데이터를 기반으로 **영양 분석 알고리즘을 통해 건강 점수를 계산합니다.**

분석 요소

- 칼로리
- 탄수화물
- 단백질
- 지방

분석 결과

- 건강 점수
- 영양 균형 분석
- 시각적 건강 리포트

---

# 💬 3. 커뮤니티 게시판 및 댓글 시스템 (F214 ~ F215)

사용자 간의 정보 공유와 소통을 위한 **멀티 게시판 기반 커뮤니티 시스템**입니다.

---

## 📌 F214 게시판 CRUD 시스템

게시판 종류

- 🍽 식단 리뷰 게시판
- 🧑‍⚕ 전문가 게시판
- 💬 자유 게시판

제공 기능

- 게시글 등록
- 게시글 조회
- 게시글 수정
- 게시글 삭제

게시글 데이터는 **게시글 ID 기반으로 LocalStorage에 저장됩니다.**

---

## 📌 F215 댓글 시스템

각 게시글에는 댓글 기능이 연결됩니다.

제공 기능

- 댓글 작성
- 댓글 조회
- 댓글 수정
- 댓글 삭제

댓글은 **게시글 ID와 연결된 데이터 구조**로 관리됩니다.

또한 **페이지 새로고침 없이 실시간으로 댓글 목록이 갱신되는 인터랙션을 구현했습니다.**
